Week 11 - Things Persist
Overview

This week I added state management to my website. The application now stores data, updates that data when the user interacts with the page, and reflects those changes in the user interface. A sandwich counter was added that allows users to increase or decrease the number of PB&J sandwiches they want to make.

Features
Displays a random cooking tip when the button is clicked
Loads cooking community member data from an external API
Uses state management to track the number of sandwiches
Updates the page immediately when the sandwich count changes
Prevents the sandwich count from going below zero

Reflection

How did adding state change the way your application behaves compared to previous weeks?

Adding state changed my application by allowing it to remember and update information while the user interacts with the page. In previous weeks, the website mainly displayed static content or fetched data from an API, but it did not keep track of changing values. With state management, the sandwich counter updates dynamically and the user interface stays synchronized with the current value.
