About This Website

This website demonstrates basic HTML, CSS, and JavaScript for making a peanut butter and jelly sandwich.

Using External Data

This website also demonstrates how JavaScript can retrieve and display external JSON data using the Fetch API.

Data is requested from an external source and does not arrive immediately. After the data is received, specific values are extracted and displayed on the page. This demonstrates asynchronous behavior and the flow of data from request, to response, to display.

Instead of showing raw JSON, the application selects specific information and formats it clearly for users.

State Management

The website also demonstrates state management using JavaScript. State allows the application to store information, update it when the user interacts with the page, and immediately reflect those changes in the user interface.

Users can interact with controls on the page to change values. The application keeps the displayed information synchronized with the current state at all times.
